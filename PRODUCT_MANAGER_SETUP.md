# DEVA Product Manager

Admin Dashboard > بەرهەمەکان > وێنە هەڵبژێرە > ناو/بەش/نرخ > زیادکردنی بەرهەم.

Uploaded images are stored in `uploads/products/`. The public app loads active Dashboard products from `/api/products` and merges them into the catalog automatically.

Run `npm install` once after this update because `multer` was added. Then start the server with `npm run dev` or `START_DEVA_LOCAL.bat`.

DEVA ONLINE - ONE-TIME ADMIN RESET (FIXED)

ئەم وەشانە Reset ـی Admin لە Render Free بەبێ Shell جێبەجێ دەکات.

1) لە Render > DEVA-ONLINE > Environment ئەمانە دڵنیابە:
   ADMIN_EMAIL = ئیمەیڵی Admin ـەکەت
   ADMIN_PASSWORD = پاسۆردێکی بەهێز (لانیکەم 14 پیت، uppercase + lowercase + number + symbol)
   TRUST_PROXY = true
   ALLOWED_ORIGINS = https://deva-online.onrender.com

2) Variable ـێکی نوێ دابنێ:
   RESET_ADMIN_ONCE_TOKEN = token ـێکی نوێ و درێژ (لانیکەم 24 پیت)
   نموونەی token ـی کۆن/بڵاوکراوە بەکارمەهێنە؛ token ـێکی نوێ دروست بکە.

3) Save, rebuild, and deploy بکە.

4) لە Logs دەبێ یەکێک لەم پەیامانە ببینیت:
   [admin-reset] one-time reset applied ...
   یان
   [admin-reset] token already applied; skipping

5) دوای Live بوون، بە ADMIN_EMAIL و ADMIN_PASSWORD بچۆ ژوورەوە.
   Reset ـەکە failed attempts و account lock پاک دەکات و 2FA کاتێک Reset دەکرێت OFF دەکات.

6) دوای Login ـی سەرکەوتوو، RESET_ADMIN_ONCE_TOKEN لە Environment بسڕەوە و Save/redeploy بکە.
   ئەگەر دواتر Reset ـێکی نوێ پێویست بوو، token ـێکی جیاواز بەکاربهێنە.
